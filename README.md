🧘‍♀️ Wellness Tracker App

A simple and user-friendly Wellness Tracker application that helps users record and monitor their daily meditation, exercise, and diet activities. The app uses local storage to save wellness entries and display them in an activity history view.

📌 Project Overview

The Wellness Tracker allows users to:

Add daily wellness activities

Store data locally on the device

View previously added wellness entries

Maintain a healthy routine through consistency and self-monitoring

This project is ideal for learning local storage handling, state management, and UI navigation.

✨ Features

🧘 Meditation Tracking

Log meditation sessions with date and notes

Helps build mindfulness and stress reduction habits

🏋️ Exercise Tracking

Track workouts, duration, and activity type

Encourages regular physical activity

🥗 Diet Tracking

Record daily meals or diet notes

Promotes mindful eating habits

📜 Activity History

Displays all saved wellness entries

Shows a friendly message when no entries exist
